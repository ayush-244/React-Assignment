# Exactspace Chat App

React chat interface for the Exactspace Technologies internship assignment.

## Features

- Send messages with Enter (Shift+Enter for newline)
- Random username assignment from `Alan`, `Bob`, `Carol`, `Dean`, `Elin`
- Avatars, timestamps, and independent like counters
- Emoji picker with search
- `@mention` autocomplete with keyboard navigation
- Light/dark theme and LocalStorage persistence

## Commands

```bash
npm install
npm run dev
npm run build
npm run lint
npm run preview
```

## Socket.IO

Optional Socket.IO realtime sync is **not implemented** in this submission so the
mandatory local chat experience stays reliable and self-contained.
